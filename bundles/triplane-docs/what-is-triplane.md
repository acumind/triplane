Triplane is a publishing engine for the agentic web. One [[okf-bundles]] in; three
audiences out — humans get a website, in-page agents get WebMCP tools, and the agent
ecosystem gets ARD discovery (see [[three-planes]]).

You are reading this through a Triplane instance right now: these docs are themselves
an OKF bundle published by the engine they describe.

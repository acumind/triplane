Fitment is defined by **coupler + lid-lock generation**, not wattage. The MG-7xx
platform (MG-650 / MG-750 / MG-900) shares the WG-series blade assembly and 54 mm
coupler; the older MG-5xx platform uses a 48 mm coupler and is **not
cross-compatible in either direction** — forcing an MG-5xx jar onto an MG-750 body
strips the nylon coupler, which then fails the misuse test in [[warranty-policy]].

| Jar / pack | MG-500 | MG-650 | MG-750 | MG-900 |
|---|---|---|---|---|
| In-box jars of [[mg-750]] | ✗ | ✓ | ✓ | ✓ |
| [[jar-set-pro]] (DH-JSP-3) | ✗ | ✓ | ✓ | ✓ |
| Legacy MG-5xx jars | ✓ | ✗ | ✗ | ✗ |
| Juicer attachment DH-JA-1 | ✗ | ✗ | ✓ | ✓ |

The juicer attachment additionally requires the high-torque mode present only on
MG-750/900 bodies manufactured after 2024-03 (serial prefix ≥ `DM24C`).
